Preguntas frecuentes

Sobre los avisos acrílicos

¿Qué necesito enviar para cotizar?

Una foto del lugar, medidas aproximadas, el logotipo y una descripción de cómo quieres utilizar el aviso ayudan a definir el alcance.

¿Todos los avisos sirven para exterior?

No. Materiales, impresión, iluminación, anclajes y sellado deben elegirse según exposición, soporte y condiciones del espacio.

¿Pueden adaptar un logotipo existente?

Sí, siempre que contemos con un archivo autorizado y con calidad suficiente para preparar la producción.

¿La instalación está incluida?

Se confirma por proyecto. Depende del lugar, el tamaño, el acceso y el sistema de montaje.
