Preguntas frecuentes

Antes de fabricar tu aviso

¿Qué datos necesitan para cotizar un aviso publicitario?

Necesitamos una fotografía frontal del lugar, ancho y alto disponibles, el logotipo o texto, uso interior o exterior y la ubicación de instalación.

¿Qué diferencia hay entre un aviso acrílico y un aviso de neón LED?

El acrílico permite placas, letras, logotipos y distintas terminaciones; el neón LED utiliza luz para destacar formas o textos. La elección depende del espacio, la lectura, el uso y el resultado visual buscado.

¿La instalación está incluida en la cotización?

Se define por proyecto. La altura, el acceso, el soporte, la conexión eléctrica y el sistema de anclaje determinan el alcance de instalación.

¿Pueden trabajar a partir de mi logotipo?

Sí, si cuentas con autorización para usarlo. Revisamos el archivo y adaptamos sus trazos cuando la fabricación o la lectura lo requieren.
